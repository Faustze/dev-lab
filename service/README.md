# service

Основной сервис на ASP.NET Core. Одна система, которая последовательно
усложняется, — а не набор независимых примеров.

| Этап | Состояние |
|---|---|
| Minimal API, явный DI, graceful shutdown | — |
| База: EF Core, миграции, транзакции, конкурентный доступ | — |
| Нагрузочный тест и профилирование (`dotnet-counters`, `dotnet-trace`) | — |
| Docker, CI, деплой | — |
| Наблюдаемость: метрики, логи, трейсы | — |
| Очередь, идемпотентность, отказоустойчивость | — |
| Kubernetes, автоскейлинг | — |

Никаких Controllers, MediatR и Clean Architecture до того, как станет понятно,
что именно они прячут.

Каждый этап сопровождается замером в [`../benchmarks/`](../benchmarks/).
