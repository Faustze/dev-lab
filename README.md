# dev-lab

Бэкенд на C# / .NET: сервис, который последовательно усложняется, и замеры на каждом шаге.

Репозиторий держится в одном формате: каждое изменение, которое должно было
что-то улучшить, сопровождается **числом до и после**. Замер без методики и
окружения сюда не попадает.

## Принципы

- **Базовая библиотека, пока её хватает.** Абстракция берётся тогда, когда
  понятно, что именно она прячет, а не вместо этого понимания.
- **Число важнее галочки.** «Добавил очередь» — не результат. «Вынес отправку
  в очередь, p99 упал с 8 с до 40 мс, при недоступности SMTP теряется
  0 сообщений вместо всех» — результат.
- **Отрицательный результат публикуется.** Оптимизация, которая не дала
  выигрыша, с объяснением почему — такой же валидный замер.
